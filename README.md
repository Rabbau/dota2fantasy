# dota2fantasy — калькулятор фэнтези Dota 2

Статический веб-калькулятор фэнтези-режима из клиента Dota 2 (эмблемы: цвет +
разряд качества + свойство). Собираешь баннер роли — получаешь рейтинг всех
игроков/дуэтов турнира под этот баннер, с разбором очков по слотам.

Сборки нет: Python-парсер + три файла в `docs/`.

---

## Запуск

Нужен Python 3.10+. Один раз поставь зависимости парсера:

```bash
pip install -r parser/requirements.txt
```

### 1. Открыть калькулятор

Статистика уже лежит в `docs/data.js`, так что можно открывать сразу — просто
открой `docs/index.html` в браузере (двойным кликом, без сервера: страница
ничего не тянет через `fetch`, все данные вшиты в `data.js` обычным
`<script>`). Выбираешь этап (Групповой / Плей-офф) и роль, крутишь слоты
баннера — рейтинг пересчитывается на лету. «Оптимальные статы» подставляют в
каждый слот лучший показатель, клик по строке — разбор очков. Настройки
баннеров сохраняются в браузере (localStorage).

Та же причина (никакого `fetch`) позволяет захостить `docs/` как есть на
GitHub Pages: Settings → Pages → Source: Deploy from a branch → `main` /
`docs`. Ссылка не сломается: страница ничего не запрашивает за пределами
своей папки.

### 2. Обновить статистику

Токен не нужен — публичный OpenDota Explorer.

```bash
# если правил ников/составы — сперва проставить steam_id
python parser/resolve_ids.py

# стата за лигу (по умолчанию TI 2026 = 19719, задаётся в .env через LEAGUE_ID)
python parser/fetch_stats.py

# другая лига по id:
python parser/fetch_stats.py 18324        # TI 2025

# турнир ещё не начался / нет матчей в базе — берём недавнюю форму:
python parser/fetch_stats.py --last 40    # последние 40 про-матчей каждого игрока
```

Перезаписывает `data/players_stat.json` (с `sample_size` по игроку и
`updated_at`) и пересобирает `docs/data.js`. После — просто обнови страницу в
браузере.

### 3. Перенастроить под другой турнир

1. Замени составы в `data/players.json` (16 команд × 5 игроков: `nickname`,
   `team`, `role` = `core`/`mid`/`support`, `position` 1..5; `steam_id` можно
   не заполнять — подставит `resolve_ids.py`).
2. Узнай id лиги на OpenDota (`https://api.opendota.com/api/leagues`, поиск по
   названию) и пропиши в `.env` → `LEAGUE_ID=...`, либо запускай парсер с id
   аргументом. Пока в лиге нет матчей — гоняй с `--last N` (недавняя форма).
3. `python parser/fetch_stats.py` → обнови страницу.

Раскладка баннеров, коэффициенты и свойства — в `data/formulas.json`, правь
там, а затем `python parser/build_docs_data.py` (без него `docs/data.js` не
подхватит изменения — стату из OpenDota заново тянуть не нужно).

## Структура

```
data/
  formulas.json      — правила: коэффициенты статов, бонусы разрядов, свойства,
                       раскладка баннеров по этапам
  players.json       — ростер: ник, steam_id, команда, роль, позиция
  players_stat.json  — генерируется парсером: средняя стата + размер выборки
parser/
  fetch_stats.py      — стата ростера за лигу/за N последних матчей (OpenDota),
                        в конце пересобирает docs/data.js
  resolve_ids.py      — проставляет steam_id по нику (OpenDota proPlayers)
  build_docs_data.py  — data/formulas.json + data/players_stat.json → docs/data.js
docs/
  index.html / app.js / style.css — сама страница
  data.js                         — генерируется, не редактировать руками
                                    (window.TI_DATA; страница читает его, а не fetch)
```

## Правила фэнтези (клиент Dota 2, версия TI 2026)

- Ростер — 5 игроков в **3 баннерах**: Основа (карри + оффлейн одной команды),
  Центр (соло-мидер), Поддержка (саппорты одной команды).
- Групповой этап — **3 эмблемы** на баннер, плей-офф — **5** (первые 3
  переносятся):

  | Баннер | Групповой | Плей-офф |
  |---|---|---|
  | Основа | 🔴🟢🔴 | 🔴🟢🔴🟢🔴 |
  | Центр | 🔴🔵🟢 | 🔴🔵🟢🔴🟢 |
  | Поддержка | 🔵🟢🔵 | 🔵🟢🔵🟢🔵 |

- Цвет = набор статов: 🔴 фарм / убийства / смерти / башни, 🔵 варды / стаки /
  руны / смоук, 🟢 замесы / Рошан / Терзатели / оглушения / курьеры / первая кровь.
- **Разряд качества** множит вклад эмблемы: I +10%, II +30%, III +60%,
  IV +100%, V +150%.
- **Свойства** (поверх разряда):
  - *Вампирическая* — +50% себе, −10% соседним эмблемам
  - *Благотворная* — +20% соседним
  - *Дружелюбная* — +50% себе, если на баннере ≥3 Дружелюбных
  - *Уникальная* — +30% себе, если она на баннере одна
  - *Фрактальная* — +60% себе, если все разряды на баннере разные
- За этап засчитывается лучшая серия роли, в ней — 2 лучшие карты.

Источники: гайды winio.ai и sportskeeda (2026). Коэффициенты статов в
`formulas.json` — приближение.

## Ограничения

- Сравнение по **среднему за турнир** (или за N матчей), а не по «2 лучшим
  картам лучшей серии» — для ранжирования игроков достаточно, но абсолютные
  числа ниже клиентских.
- **Смотрители, лотосы, безумруды** OpenDota не отдаёт — отключены в интерфейсе
  (`"available": false`). Башни — по «добито башен» (last-hit), не по участию.
- Свойства считаются в пределах одного баннера; межбаннерных эффектов нет.
- `players.json` — ростеры на момент правки; стендинов меняй руками.
